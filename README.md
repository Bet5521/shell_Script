# Linux 系统运维一键脚本集

> 面向 Linux 服务器 / 桌面的运维自动化 Bash 脚本集合，覆盖软件安装、软件源管理、防火墙配置、设备状态指示四大高频场景。

## 项目简介

本目录收录一组遵循统一设计理念的运维脚本。它们都具备：

- **自动探测**：发行版、包管理器、防火墙后端、服务管理器、LED 设备均自动识别，无需手动指定。
- **安全改动**：修改系统配置前自动备份，支持回滚；重复执行幂等（多次运行结果一致）。
- **失败可恢复**：安装 / 配置失败自动清理已生成内容（可显式关闭以保留现场）。
- **权限自洽**：需 root 时自动尝试 `sudo` / `pkexec` 提权，参数与环境变量不丢失。
- **可读日志**：实时彩色进度输出 + 结束摘要（安装路径、快捷方式、服务名、管理命令）。

## 环境要求

- `bash >= 4.0`（`set_mirror.sh` 依赖 4.0+ 的关联数组等特性）
- 常见基础命令：`curl`、`file`、`gpg`、`tar` 等；缺失时脚本会给出对应发行版的安装提示，不会静默失败
- 部分操作需 root 权限；脚本会自动尝试提权
- 设备状态指示类脚本依赖 `/sys/class/leds` 暴露的 LED 设备节点（常见于 ARM 单板机）

## 脚本清单

| 脚本 | 用途 | 运行模式 | 权限需求 | 支持范围 |
|------|------|----------|----------|----------|
| `install_pkg.sh` | 通用软件包安装 | 交互 + 非交互 | 安装到 `/opt` 通常需 root | 归档 `tar*`/`zip`、`deb`、`rpm`、可执行、`AppImage`、`script` |
| `set_mirror.sh` | 软件源（镜像）管理 | 交互 + 非交互 | 改源需 root，只读操作免 root | `apt` / `dnf`·`yum` / `apk` / `zypper`，多发行版 |
| `setup_firewall.sh` | 防火墙配置（入站白名单） | 交互为主 | 必须 root | `firewalld` / `ufw` / `nftables` / `iptables` |
| `led_status.sh` | 板载 LED 运行状态指示灯（守护进程） | 非交互（后台守护） | 必须 root | ARM/RK3328（玩客云 WS1608）及任意含 `/sys/class/leds` 的 Linux；RGB 三通道 / 单色降级 |

## 各脚本功能说明

### `install_pkg.sh` — 通用软件包安装工具
- 自动识别包类型（扩展名 + `file` 命令 + magic bytes），也可手动指定。
- 安装目录默认 `/opt`，可按环境自动判定桌面快捷方式作用范围（所有用户 / 当前用户 / 指定用户），支持 `auto`/`strict`/`skip` 失败回退策略。
- 服务注册覆盖 11 种管理器 + 系统/用户两级作用域：`systemd` / `upstart` / `sysv` / `openrc` / `runit` / `s6` / `supervisord` / `launchd` / `cron` / `rc.local` / `none`。
- root 权限提前检测；任一步骤失败自动回滚。
- 版本 `2.0.0`，退出码：`0` 成功 `1` 常规错误 `2` 参数错误 `3` 权限不足 `4` 不支持的包类型。

### `set_mirror.sh` — 软件源（镜像）管理工具
- 自动识别发行版与版本，选择对应包管理器与源配置文件格式。
- 交互式菜单 + 命令行双模式；内置候选源、手动 URL、一键恢复默认。
- 修改前自动备份，支持 `--rollback`；重复执行幂等；失败安全退出。
- 内置连通性与速度（延迟/下载速率）检测，按结果自动选最优源。
- 自动处理 GPG 密钥（`NO_PUBKEY` / 签名无效 / 公钥过期），下载导入并复检。
- 版本 `1.0.0`。

### `setup_firewall.sh` — 防火墙配置工具
- 设计模型：入站白名单（`INPUT DROP`）+ 出站放行（`OUTPUT ACCEPT`，可切严格）。
- 后端自动探测，优先级：`firewalld` > `ufw` > `nftables` > `iptables`。
- 统一规则接口（放行 / 封禁 / 删除 / 持久化）在各后端下语义一致且幂等。
- IPv4 + IPv6 双栈；Docker 兼容（不破坏 nat 表 / FORWARD 策略 / DOCKER* 链）。
- SSH 防暴力破解（各后端原生实现）；服务预设模板（含 Oracle DB 1521）。
- 规则文件化 + 备份回滚 + 试运行超时自动回滚。

### `led_status.sh` — 板载 LED 运行状态指示灯（守护进程）
- 持续后台运行，通过板载 LED 实时反映设备运行状态：
  - **通电**：第一种颜色（默认蓝）常亮；
  - **联网**：第二种颜色（默认绿）常亮；
  - **有负载**：在绿灯常亮基础上，第三种颜色（默认红）闪烁，闪烁频率随系统负载升高而加快。
- 自动探测 `/sys/class/leds` 下 red/green/blue 三通道；单色 LED 板自动降级（以常亮 / 闪烁区分状态）并告警。
- 状态自动切换：网络探测（默认网关 ping，失败回退公网 DNS）；负载 = 1 分钟 loadavg / CPU 核数归一化。
- 命令：`start` / `stop` / `restart` / `status` / `run`（前台调试）/ `install`（systemd 开机自启）/ `uninstall` / `list-leds`。
- PID 文件防重复启动（幂等）；退出（SIGTERM/SIGINT）自动清理 LED 状态；改写 systemd unit 前自动备份。
- 可用环境变量 `LED_BLUE` / `LED_GREEN` / `LED_RED` 指定非标准 LED 路径，`BUSY_THRESHOLD` / `POLL_NET` / `POLL_IDLE` 调优阈值。
- 版本 `1.0.0`，退出码：`0` 成功 `1` 通用错误 `2` 权限不足 `3` 无可用 LED 设备 `4` 参数错误 `5` 已在运行。
